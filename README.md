# Já tô na Ponte! — artes

Artes do perfil [@jatonaponte](https://www.instagram.com/jatonaponte/), sobre o trânsito da Ponte Rio-Niterói.

- `index.html`: página de links da bio (câmeras e contatos oficiais).
- `artes/`: posts agendados (JPEG 1080×1350; carrosséis com sufixo -1, -2, -3). O n8n publica a partir daqui.
- `artes/calendario.json`: data, tipo, formato e arquivos de cada post.
